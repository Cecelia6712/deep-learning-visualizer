# CNN 可视化实验室 (CNN Vis-Lab)

> 一个极致直观、零依赖、无认知负担的卷积神经网络 (CNN) 交互式可视化教学工具。

本项目通过纯前端的原生技术，将深度学习（尤其是 CNN）中抽象的概念（如 Padding、Stride、卷积核滑动、池化等）转化为可交互的视觉实验。旨在帮助学习者、开发者或任何对 AI 感兴趣的人，通过“动手玩”来建立直观的物理直觉。

##  设计理念与特性

- ** 学术与极简风格**：摒弃花哨的动画和刺眼的色彩，采用纯白背景、极简边框、低饱和学术配色（深蓝/墨绿/深红），让你专注知识本身。
- ** 绝对零依赖**：没有任何前端框架（无 Vue/React）、没有打包工具（无 Webpack/Vite）、没有第三方 UI 库。纯原生 HTML/CSS/JS，代码即文档，随时开箱即用。
- ** 全景上下文 (Overview)**：拒绝“管中窥豹”式的局部演示。每一个滑窗计算，都能让你同时看到输入原图、完整的特征图以及当前计算的位置。
- ** 极致的控制感**：告别简陋的下拉框。所有参数调整均采用极客风的步进器（Stepper），并配有动态公式推导和实时矩阵联动。

##  如何本地运行？

因为本项目是**零依赖的纯静态单页应用 (SPA)**，你不需要安装 Node.js，也不需要跑 `npm install`。

1. 克隆或下载本仓库到本地。
2. **双击打开 `index.html`** 即可在浏览器中体验。
3. *(推荐)* 如果你想获得更好的本地开发体验，可以使用 VS Code 的 `Live Server` 插件，或者运行 `python -m http.server 8000` 启动一个本地服务器。
