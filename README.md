\# 🧠 CNN 可视化实验室 - 项目架构与开发契约



> 这是一份具有绝对约束力的工程契约。在写任何代码之前，请完整阅读本文档与 `踩坑指南.md`。本项目旨在打造极致直观、无认知负担的深度学习可视化工具。



\## 一、 核心架构（绝对不可破坏）



1\. \*\*零依赖单页应用 (SPA)\*\*：

&#x20;  - 只有 `index.html`，不使用任何前端框架（Vue/React）、不使用打包工具、不使用 Canvas 画静态矩阵。

&#x20;  - 导航切换仅通过原生 JS 控制模块的显示与隐藏。

2\. \*\*模块化注入机制 (`Lab.register`)\*\*：

&#x20;  - 所有模块必须包裹在 IIFE `(function(){ ... })()` 中，避免全局污染。

&#x20;  - 每个模块必须有 `id`, `index`, `title`, `desc`, `template()`, `init(root)`, `onHide()`。

&#x20;  - \*\*禁止在 `template()` 中写内联事件\*\*，所有事件在 `init()` 中通过 `root.querySelector` 绑定。

3\. \*\*生命周期清理\*\*：

&#x20;  - 凡是包含 `setTimeout`, `setInterval`, `requestAnimationFrame` 或 Canvas 动画的模块，\*\*必须在 `onHide()` 中彻底清理定时器\*\*，防止在后台偷跑消耗性能。



\## 二、 UI / UX 设计铁律（违反将被打回）



1\. \*\*学术风格\*\*：

&#x20;  - 背景纯白，深灰字体，极简边框。

&#x20;  - 标题用衬线体（Georgia/宋体），正文无衬线体，公式/数字用等宽体（Consolas）。

&#x20;  - 高亮仅使用低饱和色：深蓝 `#2980b9`，墨绿 `#27ae60`，深红 `#c0392b`。

2\. \*\*控件克制\*\*：

&#x20;  - \*\*绝对禁止使用 `<select>` 下拉框！\*\*

&#x20;  - 所有数值调整必须手写步进器 `<div class="stepper">`。

3\. \*\*矩阵渲染\*\*：

&#x20;  - 必须使用 CSS Grid + `div` 绘制矩阵（方便独立高亮每个格子）。

&#x20;  - \*\*每个矩阵动态生成时，必须显式设置 `grid-template-columns`\*\*。

4\. \*\*全景视图原则\*\*：

&#x20;  - 任何动画或计算过程，必须提供“全局上下文”。必须让用户看到输入原图、完整的特征图和当前滑动的窗口，不能只放局部切片。



\## 三、 当前模块清单 (已完成)



\- `01` \*\*二维互相关\*\*：滑动窗口、配对待计算、柱状图累加。包含折叠/展开按钮。

\- `02` \*\*多通道与 1×1 卷积\*\*：Cin/Cout 独立区分、叠层卡片、逐通道推导、1×1 交叉连线。

\- `03` \*\*池化层\*\*：Max/Avg 切换、重叠与不重叠对比、全景窗口。

\- `04` \*\*Padding 与 Stride\*\*：预设表格与自定义行联动、公式代入、补零虚线与跳跃轨迹。

\- `05` \*\*LeNet 张量流水线\*\*：2.5D 卡片、真实特征图点阵、尺寸直观缩放、全连接交叉网络。

\- `06` \*\*过拟合实验台\*\*：Canvas 动态折线、早停/Dropout/数据增强三味解药实时干预。



\## 四、 未来扩展方向 (Roadmap)



1\. \*\*第 4 章补全\*\*：

&#x20;  - 感受野推导、深度可分离卷积参数量对比、平移不变性演示。

2\. \*\*第 1\~3 章基础\*\*：

&#x20;  - 线性回归、Softmax、多层感知机（MLP）、激活函数曲线。

3\. \*\*第 5 章及以上\*\*：

&#x20;  - AlexNet/VGG 结构对比、ResNet 残差连接、BN 数据分布动画。
